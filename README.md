# 运行方法

1. 在当前目录中新建一个名为 `.env` 的文件，内容如下：

   ```text
   OPENROUTER_API_KEY="sk-xxx"
   ```

   其中 `sk-xxx` 替换为你的 OpenRouter API Key。

2. 启动服务器

   ```bash

conda activate mcpdemo
uv run start.py
   ```

3. 打开浏览器，访问 `http://localhost:5000`。
