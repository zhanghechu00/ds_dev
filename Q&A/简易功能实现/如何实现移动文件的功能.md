### 复制文件 (`copy_files`) 的实现原理

1.  **遍历源目录**：
    使用 `os.listdir(source_folder)` 获取源文件夹下的所有文件和子文件夹名称。

2.  **构建路径**：
    使用 `os.path.join` 分别构建源文件路径 (`s`) 和目标文件路径 (`d`)。

3.  **执行复制**：
    *   检查当前项是否为文件 (`os.path.isfile(s)`)。
    *   如果是文件，调用 Python 标准库 `shutil` 模块的 `copy2` 函数：
        ```python
        shutil.copy2(s, d)
        ```
        *注：`copy2` 相比 `copy` 的优点是它会尝试保留文件的元数据（如修改时间、权限等）。*

4.  **异常处理**：
    使用 `try-except` 块捕获可能出现的权限错误或路径错误，并将错误信息收集起来返回给用户。

### 如果您需要“移动文件”功能

如果要实现**“移动文件”**（即剪切并粘贴），实现逻辑非常相似，只需将核心的复制函数替换为移动函数即可：

1.  **核心函数替换**：
    将 `shutil.copy2(s, d)` 替换为 `shutil.move(s, d)`。

2.  **逻辑区别**：
    *   `shutil.move` 会将文件从源路径移动到目标路径，源文件会被删除。
    *   它通常比“复制+删除”更高效，因为在同一个文件系统下，它只需要修改文件系统的索引，而不需要移动实际的数据块。
