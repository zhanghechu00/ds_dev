检索文件内容的功能是通过 mcp_server_shihua.py 中的 `verify_word_consistency` 函数实现的。这个函数利用了 `python-docx` 库来解析 Word 文档（.docx）。

具体实现逻辑分为以下几个步骤：

1.  **加载文档**：
    使用 `Document(file_path)` 加载指定路径的 Word 文档。

2.  **检索正文（段落）**：
    *   遍历文档中的所有段落 (`doc.paragraphs`)。
    *   检查关键字 (`keyword`) 是否存在于段落文本中。
    *   如果存在，假设关键字后面紧跟着值，使用 `split(keyword, 1)` 将文本分割。
    *   取分割后的第二部分，去除首尾空格以及可能存在的冒号（`: ` 或 `：`），提取出“值”。

    ```python
    for para in doc.paragraphs:
        if keyword in para.text:
            parts = para.text.split(keyword, 1)
            if len(parts) > 1:
                val = parts[1].strip().lstrip(":：").strip()
                text_values.append(val)
    ```

3.  **检索表格**：
    *   遍历文档中的所有表格 (`doc.tables`)。
    *   遍历表格的每一行 (`table.rows`) 和每一个单元格 (`row.cells`)。
    *   如果某个单元格包含关键字，则假设**同一个行中的下一个单元格**包含对应的值。
    *   提取下一个单元格的文本作为“值”。

    ```python
    for table in doc.tables:
        for row in table.rows:
            cells = row.cells
            for i, cell in enumerate(cells):
                if keyword in cell.text:
                    if i + 1 < len(cells): # 确保有下一个单元格
                        val = cells[i+1].text.strip()
                        table_values.append(val)
    ```

4.  **比对结果**：
    *   分别收集正文中的值 (`text_values`) 和表格中的值 (`table_values`)。
    *   检查这两个列表是否有交集（即是否存在相同的值）。
    *   根据比对结果返回“内容一致”或“内容不一致”的提示信息。

这种实现方式比较简单直接，适用于结构比较规范的文档（例如：正文中是“项目名称：XXX”，表格中是“项目名称”|“XXX”）。
